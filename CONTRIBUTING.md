# Contributing to nembot

Thanks for your interest!

- **Issues are welcome:** bug reports, questions, data problems and feature ideas. For a download that stalls,
  please include the output of `kill -USR1 <pid of nembot-chat>` (see "Known issues" in the README).
- **Pull requests aren't accepted for now.** nembot is licensed under the PolyForm Noncommercial License with
  commercial licences available, and outside code would need a contributor licence agreement first. If you have
  a fix, describe it in an issue instead, and it may be implemented.
